# 项目工作区 PM 入口

## 范围与来源

沿用已审本机入口提交 `cafcba35163955f008b6117914281704812004f7` 的产品范围，工作区实际拥有项目导航，入口与通用 SessionSidebar 相邻。SessionSidebar 保持基线字节不变。此切片没有持久 PM 身份、聊天、模型、工具派发、外部连接或权限变更，打开后明确展示运行时尚未接入。不是可执行 PM Bot 交付。

## 要求及验收

- R01：当前匹配的项目会话或非匿名项目草稿只有一个入口；quick、匿名、未知和冲突快照隐藏。使用 sessionId，不能继承过期 activeSession 的项目。
- R02：展示当前目录；同项目切会话保留展开状态，跨项目立即关闭旧区域，再打开只显示新项目。cwd 是展示分组，不是可信宿主项目身份或权限证明。
- R03：Enter 打开并聚焦标题，Escape 关闭并回到入口；搜索不改变归属，不创建普通会话。
- R04：保持既有侧栏展开和会话选择；默认 1200×800、最小 800×600 无横向溢出。

生产组件单测先红后绿，配合既有 Sidebar、Workspace 草稿/项目回归。现有 UI-006 的 `test:sidebar-expansion:headless` 演练实际生产组件和合成 store；真实 Chromium 保留沙箱，不能称原生 Tauri、数据库或权限验收。当前云端共享依赖的字体资源被 Vite allowlist 拒绝，截图使用回退字体。

## 治理与发布边界

工作区是项目侧栏的实际宿主，沿用可信基线对 `src/pages/Workspace/*.tsx` 的映射，不修改 registry、validator、hooks 或保护。正式 planner 所选全部场景均须取得相应精确提交回执，不能只凭 UI-006 通过发布。

macOS 标准桌面工作流可构建应用并验证窗口/截图，但不代替项目切换交互。原生、Windows 和远端场景尚无本候选回执时必须标未运行。旧入口及停止的外部消息候选保留，不能混入本批。
