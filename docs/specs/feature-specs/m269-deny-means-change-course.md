# M269：拒绝一条审批只否这一条操作，不是停整单

## 现场（2026-11-08，v1.110.0，会话 `833ac8cb`）

- 编排方拒绝了一条 `python3 - <<'PY'` 读场景登记表的命令，并按 M265 附了说明：
  「不要用 python 读 JSON。请运行：jq …」。
- 模型读到的被拒结果只有一句「工具调用被用户拒绝，未执行，不要用另一个工具绕过」，
  说明接在后面；没有任何文字说明「整单没有取消、可以换办法继续」。模型由此认为
  整单被叫停，写了一份「阻断总结」让用户自己去看后台测试结果。
- 该回合结束后，thin 派生看到「没有未结算的 objective / 没有未完成投递」，
  把会话投影成 `ended / 最终回答已完成`，尽管改动已回滚、只差读测试结果与提交。
  编排方只能重新唤醒它。

## 根因（R3）

`src-tauri/src/agent/thin_derive.rs` 的终态推导：`terminal` 取到最新的
「最终回答已完成」后，只要没有停止意图（`chat_session_cancel_intents`）且上一次投影
不是 `waiting_wake`/内部措辞的 `waiting_user`，就直接
`ThinState::ended(reason)`。这条路径只看「模型说完话了」，不看「任务是否已经落地」，
于是模型把「被拒」理解成「停单」并写完总结时，会话被一起结掉。
`settle_objectiveless_wake` 只是另一个在同一会话上空转的恢复入口，不是本次的第一落点。

## 规格

- **R1 被拒文案**：被拒结果必须明确写出：被拒的只是这一条操作，任务没有取消；
  不要用别的工具做同一件被拒的事，但可以换办法继续完成任务；如果附有说明，按说明做。
  不得削弱「不准绕过」：同一个被拒的动作不能换个写法再做一遍。
- **R2 真停整单**：用户真的要停时走现有「停止」（`chat_session_cancel_intents`），
  不靠拒绝审批表达。
- **R3 未交付不结束**：任务还没交付、PR 没开或没合时，模型回合以阻断总结结束不得把会话
  结成 `ended`，应进入真实的等待/继续状态（有真实唤醒源）。
- **R4 权限判定零改动**：批准/拒绝、作用域、`reason`、记账都不变；只改给模型看的文字
  与会话投影。

## 决策

1. **文案只加「范围」不改「禁止」**：`DENIED_BY_USER_CONTENT` 首句保持
   `Tool call denied by the user. The requested action was not executed; do not bypass this decision with another tool.`
   原样，后接一句范围说明（仅此一条、任务未取消、可换办法、有说明按说明）。
   不写说明的拒绝也带这句范围说明——M265 R5 的「逐字相同」约束被本规格取代，
   但「不得绕过」的原句必须仍在首位且逐字不变。
2. **阻断总结不是终态事实**：在 `thin_derive` 的「最终回答已完成」终态分支之前加守卫：
   最新最终回答被识别为阻断总结、且没有已交付/已合并/未完成投递事实、也没有停止意图时，
   复用 `continue_state` 写一条 `thin-continue-*` 唤醒并投影 `waiting_wake`，
   让系统自己把剩余工作接回来。
3. **识别用显式措辞，不做语义猜测**：只匹配明确的停单/受阻表达（如「任务已停止」
   「已停止本次」「整单停」「无法继续」「不能继续」「无法推进」「被阻塞」「审批被拒绝」
   「blocked」）。正常完成总结不含这些词就不受影响；已合并且收尾闭环的会话在更早的
   终态分支就 `ended`，不经过本守卫。
4. **停止优先**：`stopped_at > 0` 时不进入阻断守卫，用户停的仍照旧结束（R2）。

## Spec Amendment（相对 M265）

M265 R5 要求「不写说明时拒绝文本与常量逐字相同」。本规格为了 R1 在被拒文本里补一句
范围说明，因此不再逐字相同；M265 的**禁止绕过**语义与首句文字保持不变，M265 R4
（说明不改变判定）继续有效。

M130 R1 的单元断言原本要求交付类拒绝（`Deliver_changes` 被拒）的 `content` **整串等于**
`用户不允许推送，请在本地完成并说明`。M269 之后该串是「M130 首句 + M269 范围句」，
因此断言改为：首句仍是 M130 原文（用户决定被命名），且 M269 的「the task is not cancelled」
必须存活。实现上拒绝改写从「替换到第一个空行」收窄为「只替换第一行」，
既保住用户自己写的说明（M265 R4），也保住范围句。
