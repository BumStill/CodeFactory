# CF-IM-001 一键式 IM 绑定与通知诊断

当前 IM 通知不能继续把手填 Webhook 当主路径。用户目标是点一下把 CodeFactory 绑定到企业微信/飞书群，之后任务完成、失败或等待批准时能在手机收到可靠通知。

## P0：本地向导式绑定

设置页不再以手填 Webhook 作为主路径；主路径是“选择 IM → 完成连接/授权 → 自动发送诊断消息 → 成功后保存绑定”。第一批目标是企业微信、飞书。高级用户仍可展开“高级：手动 Webhook”作为降级路径。

## 体验要求

- 未绑定态显示“手机通知”和“一键绑定 IM”。
- 选择企业微信/飞书后展示对应绑定步骤。
- 绑定前必须发送诊断消息，成功后才保存。
- 失败必须显示可理解原因：权限不足、机器人未进群、Webhook 过期/签名错误、网络不可达、消息格式不兼容。
- 不把 IM token、Webhook secret 或群消息内容暴露给模型。

## 后续阶段

P1 可接入可选 relay/OAuth/扫码能力，实现真正一键创建/安装机器人；local-first 的手动降级路径必须保留。
