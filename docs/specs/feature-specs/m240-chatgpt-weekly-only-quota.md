# M240：按周计量的 ChatGPT 套餐也要读得到用量

## 问题
用户升级 ChatGPT 套餐后，用量显示「用量接口已变更」，界面停在推算值，并按超限处理。

## 根因（从代码推断，真实响应尚未看到）
解析要求同时有 `primary_window` 和 `secondary_window`，并按字段名认定 5 小时和每周。用户说新套餐按周计算，如果响应只有一个窗口，解析就会失败。

## 要求
- R1：按 `limit_window_seconds` 判断窗口，不小于一天算每周。没有这个字段时按原来的位置判断。
- R2：只有每周窗口时，5 小时用量记为 0，每周上限照常生效。
- R3：读不到每周用量时继续判为读不出来，路由按超限处理，不允许放行。
- R4：解析失败时日志只记录字段名，不记录数值和凭据，用来确认真实格式。

## 验收
- 单测：`quota_live` 模块。
- 真机：装上后 `get_quota` 的 `refresh_error` 为空，每周用量与用户在 ChatGPT 看到的一致。
