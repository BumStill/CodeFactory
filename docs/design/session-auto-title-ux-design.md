# 会话自动语义命名 UX 设计

## 体验原则

- 标题帮助用户识别工作主题，不重复用户的命令原句。
- 对话是主任务，命名是后台增强；命名状态不得阻塞或抢占聊天。
- 自动标题形成后保持稳定，避免侧栏项目在用户阅读时持续跳名。
- 手动重命名是最终决定，自动流程永不覆盖。
- 完整标题可能通过 tooltip、accessible name、Welcome 和用量页暴露，因此脱敏不能依赖视觉截断。

## 状态与文案

### 草稿

用户尚未发送时显示：

```text
新会话  ·  草稿
```

草稿不根据输入框中的未发送文字预生成标题，避免保存或外发尚未提交的内容。

### 首条消息已发送

会话物化后暂时保留“新会话”。命名在正文回合结束后的后台 idle 时段进行，不增加 spinner、阻断 toast 或第二条聊天消息；若用户已经排队下一条消息，则继续让正文优先。首轮正文应立即进入正常发送/流式状态。

### 自动命名成功

`session_updated` 到达后，侧栏、顶栏、搜索、Welcome 和用量详情切换到同一标题。更新不得：

- 抢走输入框或重命名输入框的焦点；
- 改变当前会话选择；
- 因标题更新单独把会话重新排序；
- 弹出“命名成功”提示或写入聊天正文。

### 自动命名失败

有安全 fallback 时直接显示 fallback；没有时保持“新会话”。聊天继续正常工作，不显示 Provider 错误。用户仍可通过双击或“更多操作 → 重命名”设置标题。

### 手动重命名

用户提交非空标题后立即显示人工标题。若自动请求仍在运行，迟到结果静默丢弃。后续消息、模型切换、重启和后台任务都不得重新开启自动命名。

## 标题内容规则

推荐形态是简短的“主题 + 结果”：

| 用户输入 | 合理标题形态 | 不可接受 |
| --- | --- | --- |
| “新建 session 的名字，要自动进行总结个合理的” | 会话自动命名优化 | 新建 session 的名字，要自动进行总结个合理的 |
| “请帮我看看为什么 CI 又挂了” | CI 失败原因排查 | 请帮我看看为什么 CI 又挂了 |
| “Can you make the sidebar usable on mobile?” | Mobile Sidebar Usability | Can you make the sidebar usable on mobile |
| “继续” | 保持新会话，等待更多上下文 | 继续 |
| 带 token、绝对路径和堆栈的登录问题 | 登录故障排查 | 任意 token、路径、邮箱、URL 或堆栈行 |

标题遵循用户消息的主语言。技术专名可以保留，但不得为了显得具体而暴露本机路径、账号信息、分支、UUID、secret、代码或日志原句。

## 搜索与可访问性

- 搜索继续按最终标题匹配；生成前的 placeholder 不应索引原始 prompt。
- 侧栏视觉上可以截断，但 tooltip 和 `aria-label` 使用同一个经过校验的完整标题。
- 标题变化不使用强制 live announcement；读屏用户重新聚焦会话项时读取新标题，避免后台更新打断正文朗读。
- 手动重命名输入框保持现有键盘语义：Enter 提交、Escape 取消、blur 提交；自动更新不能触发该输入框关闭或重置。
- 不只依赖颜色区分草稿、匿名或命名状态。

## 视口与稳定性

- 1366×768 和 800×600：新标题不得挤压模型、权限和设置入口；超长结果必须在写库前裁剪，而不只靠 CSS。
- 375×812 和 200% zoom：侧栏行保持单行标题与可达的更多操作；自动更新不产生横向滚动。
- 生成前后会话行高度不变，避免列表抖动。
- `prefers-reduced-motion` 下不引入命名动画；默认也不需要持续旋转图标。

## 关键验收场景

1. 中文首条消息发送后，正文立即开始；随后标题从“新会话”变为语义短语。
2. “继续”不会成为标题；首轮形成可见结论后最多延迟重试一次。
3. 输入包含 secret、邮箱、手机号、URL、绝对路径、UUID、代码和日志，所有标题 surface 均不出现这些内容。
4. 自动请求在途时手动重命名，迟到结果不覆盖人工标题，重启后仍保持。
5. Provider 不支持、断网、超时和非法输出时，聊天不报错，显示安全 fallback 或“新会话”。
6. 匿名会话始终显示“匿名会话”，退出即丢弃，不出现后台命名或 Usage。
7. 打开升级前旧会话，标题保持不变，不出现批量改名或命名状态。
8. 侧栏、顶栏、搜索、Welcome、用量详情显示一致，且完整 accessible name 不包含原始 prompt。

## 非目标提示

Session 标题修复不自动改变 task segment 或 checkpoint 的原文标签。若这些标签仍在其他 UI 中显示，验收报告必须明确标注为后续风险，不能用本功能的通过结果替代全产品隐私审计。
