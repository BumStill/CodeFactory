# 会话控制收敛 UX 设计

## 状态层级

普通回复保持自然对话。completion review 开始后，流式尾部从 `Thinking` 切换为一句低噪声状态，不使用独立状态卡：

```text
正在补充验证 · 最终回复前仍需补齐执行证据
```

`ready` 后显示：

```text
正在整理最终结果
验证证据已满足，正在生成最终回复
```

达到内部 segment guard 时不显示轮次或“上限”，而是：

```text
已保存当前进度，正在继续处理…
```

续段失败或重启识别到悬空回合时显示：

```text
执行意外中断，已保留完成内容。  继续执行
```

## 内容规则

- 显示：阶段、安全工具名称、最近活动、累计耗时、停止/恢复边界。
- 不显示：raw recovery prompt、模型推理草稿、完整命令参数、文件正文、凭据、完整 tool result。
- recovery 原因使用产品文案，不直接展示英文 blocker：
  - 默认：「最终回复前仍需补齐执行证据」。
  - ready：「验证证据已满足，正在整理最终结果」。
- 工具名称使用现有安全标签；未知工具显示「执行检查」，不输出 args。

## 交互

- 输入框的取消按钮 title/辅助文案改为「停止后续生成」。
- 状态行不新增第二个取消按钮，避免重复入口；就近文案说明取消不会回滚。
- 只有自动接管失败或重启后没有活跃 owner 时显示「继续执行」；它复用原 root goal，不产生含糊的新目标。
- 用户切换会话后，侧栏继续显示该会话运行中；返回时状态卡仍在同一尾部。
- 完成后状态卡被最终回复替换；验证不完整时最终回复下方保留 amber 警告。

## 可访问性

- 状态行使用 `role="status"`、`aria-live="polite"`，阶段变化可被读屏感知。
- 运行中使用中性蓝色；验证不完整使用 amber；不使用红色表达正常恢复。
- 动画遵守 `prefers-reduced-motion`，不依赖无限旋转图标传达状态。

## 视口验收

- 1366×768：状态行跟随正文，不遮挡工具证据和输入框。
- 800×600：状态行完整显示阶段、当前步骤和恢复边界；页面无横向滚动。
- 长达 44 分钟且跨多个 segment 的模拟回合：计时连续增长，目标不因内部 guard 结束，也不只显示 `Thinking`。
- 深浅主题下正文、边框、状态和警告均可读。
