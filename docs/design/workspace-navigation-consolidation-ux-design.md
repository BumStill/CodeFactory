# Workspace 顶栏收敛 UX 设计

## Workspace 顶栏

从左到右：会话侧栏收展、会话标题/路径、匿名状态、模型、推理强度、本地工作树、会话交付状态、按需任务活动、设置。设置是唯一的全局导航入口；新建会话只保留在左侧会话栏，避免两个“＋”表达同一动作。侧栏收起后，同一顶栏位置切换为“展开会话侧栏”，保证恢复入口始终可见。

移除：三态主题切换、画像、进化审查、能力评测、资源中心、AI Coding OS，以及已经废弃的规范/计划入口。pending memory 不再以额外按钮挤占顶栏；进入「设置 → 功能 → 进化审查」查看待审项。



### Git 与交付状态

- 「本地工作树」是单一可点击摘要，直接显示 `分支 · N 个本地变更 · 已同步/领先 N/落后 N`。提交历史、远程仓库和恢复快照进入本地 Git 抽屉，不在顶栏重复放图标。
- 「会话交付状态」回答 `PR #N · CI 状态 · 合并状态 · 已上线版本`。会话持久保存 PR 关联，即使合并后工作树已切回 `main`，也不能丢失本会话的交付对象。
- CI 数据只取对应 GitHub PR 的 head SHA/check-runs；合并取 PR `merged_at/merge_commit_sha`；版本仅在 latest release tag 包含该 merge commit 时显示「已上线」。远程不可用必须明确显示，不得误报为「无 PR」。
- 自动检查点不是进度或质量指标。只有与当前工作树存在实际差异的快照才显示为「恢复 N」，并放在本地 Git 抽屉内。
- 任务活动不是历史计数器。`completed`/`cancelled` 不常驻；`pending` 显示「待执行」、`running` 显示「正在执行」，技术失败按 objective projection 显示「正在诊断/修复/等待退避/验证」。只有 typed `core_input_required/needs_business_decision` 才显示「需要你提供输入/选择」。

## Workspace 注意力层级

- 会话正文是主表面。`TasksColumn` 与 `ExecutionStream` 不得常驻正文顶部。
- 项目任务仅在运行、待处理或恢复时，于顶栏显示不超过 30px 高的「任务活动」入口；点击后从右侧打开 360–420px 抽屉，承载 objective owner、停止、失败归因、最近真实进展、下一次观察、规范来源与验收结果。技术状态没有人工继续/重试动作；必要输入或业务决定按 typed state 显示唯一动作。无活动 objective 时入口隐藏。
- 左侧栏顶部采用「会话 + 紧凑＋」工具栏；会话按今天、昨天、过去 7 天、更早分组。行高不超过 46px，默认无卡片边框；当前会话以 2px 强调线和轻背景标识，类型只用图标表达，更多操作仅在 hover、键盘聚焦或菜单打开时显示。
- 成功工具调用是低强调活动行，展开前不超过 30px；连续三项以上成功调用归组为「已完成 N 个操作」。运行、权限、拒绝、取消和失败不得归组；失败首行始终直接显示。

## 设置「功能」

从 Workspace 顶栏进入设置时默认打开「功能」。内容为可读的导航卡，而不是另一排图标：

```text
功能
[我的画像]    偏好、长期记忆与可撤销建议
[进化审查]    审核会话学习与激活候选
[能力评测]    查看 Evals 与能力基线
[资源中心]    管理知识与技能
[AI Coding OS] 检查本地控制平面状态
```

卡片使用图标、标题、说明和右箭头；点击进入现有页面。外观仍在独立 tab，不在功能页重复主题控件。

## Welcome 首屏

- 内容宽度从 `max-w-2xl` 调整为 `max-w-3xl`，桌面 `px-4/6`，垂直间距 16px。
- Hero 改为左对齐紧凑品牌行：40px 品牌块、20px 标题、12px 中文说明；当前目录/模型在右侧或下一行显示。
- 用量卡桌面为横向摘要：左侧今日数值，右侧 28 天趋势；较窄内容区堆叠，但卡片不形成大片空白。
- 趋势使用 28 个竖条，高度和同一蓝色色相从淡到深共同表达相对用量。无使用/缺失均为可见的最淡蓝色短条；今天位于最右侧，不额外画白框。摘要中不画虚线、灰色状态、黄色角标、`×`、`·`、`!` 字符，也不做 hover 放大。缺失与零值的完整语义保留在 tooltip/读屏和设置详情。
- 示例任务统一为中文，两列展示；375px 下单列。

## 视口验收

- 1366×768：Welcome 用量卡 108–150px；趋势宽度至少占卡片内容区 45%；首行任务建议可见。
- 800×600：顶栏无重叠；Welcome 用量卡不超过 190px；详情入口和「可以试试」可见；整页无水平溢出。
- 375×812：Hero 左对齐、任务建议单列、用量卡不超过 210px；28 个趋势条全部在卡内或仅趋势区局部滚动，整页不横滚。
- 深浅主题的小字号正文达到可读对比度；焦点环清晰，趋势左右方向键按相邻日期移动。
