# R2：有界 shell 精确意图证明

本切片在普通 shell 调用执行前预测精确文件结果，不改变执行、权限审批或沙箱设置，也不声称支持任意 shell 的来源证明。

## 支持范围

解析器必须消费完整 POSIX 输入：字面量参数、引号、`>` / `>>` 重定向，以及有界的 `&&` 或 `;` 顺序组合。操作包含 printf（字面文本、`%s`、`%%` 和明确支持的字符转义）、无歧义 echo、读取普通文件的 cat、cp、mv、rm。变量/命令展开、通配符、管道、后台执行、heredoc、函数定义、环境前缀、未知程序及不支持的选项使整条输入不获得证明，不保留前半段证明。Windows 实际执行 PowerShell，因此本轮不产生 POSIX 证明。

## 精确意图与读取依赖

宿主将操作模拟在有界文件状态表中。初态仅从工作区普通文件读取；拒绝可执行文件、符号链接、硬链接及不安全路径。复制、移动、cat 的源文件即便最终未变也必须保留为读取依赖。一个版本化、多路径 locator 存入既有文件观察回执，每项记录路径、原始摘要和预期最终摘要；完整有序清单生成聚合前置/预期摘要。缺失文件使用已有 absent 摘要。

交付加载器按组核验所有前置摘要：只有每个输入都可从可信基线或已接纳回执链到达，才一次性接纳本组全部边。使用有界固定点处理同毫秒回执，不允许循环或外来输入自我认领。不能只核验最终 diff，否则把被排除的外来文件复制到新文件会洗成任务输出。

结算和恢复必须观察清单全部成员，只能整体标记 applied，不能局部成功。聚合摘要须与清单重新计算结果一致。既有单路径 native write/edit locator 和 observer 保持兼容。未知脚本沿用既有执行与恢复流程，但不新增归属证明。

## 并发与边界

无关并发文件不进入意图清单。被观察路径发生变化且与执行前预期不同，结算为冲突；即使恰好等于预期，也只能证明这些精确内容，不能推断命令没有其他副作用。外来前置内容不能连接可信基线。其他未计划变更仍由交付树门禁拒绝。

限制：命令 64 KiB、32 个语句、64 个路径、每文件/单次输出 2 MiB、来源总计 8 MiB；所有读取有界。路径逃逸、链接和 mode 边界不降级接受。

## 验收

使用真实宿主 shell 验证创建/修改、复制/移动/删除、追加与引号/格式语义、任务预暂存、外来前置内容、无关未跟踪/预暂存文件、动态语法、mode/链接/预算限制、聚合恢复观察，以及生产交付到本地 bare remote 的精确内容。任意编译器/脚本生成和 Windows 来源兼容仍未覆盖，不能称完整 R2 交付已完成。

## 恢复不扩权

shell 清单仅补充交付内容证据，不能替代原有 generic 命令恢复合同。新 shell 清单与 generic 合同同时保存；没有 generic 观察器时不借清单放行原本不可观察的命令。补充清单不改变既有 generic replay_policy；原本 never_after_dispatch 的调用不因文件未变自动重新执行，既有文件定向追加的 exact_if_unchanged / at-most-once 规则也保持原样。只有实际前台终态成功才能把补充文件证据标为 applied；崩溃后即使文件恰好等于预期，也不能仅据此把整条命令标 Done。过渡版本留下的纯 shell 清单、没有 generic 合同的未知回执，保持等待对账。native write/edit 的既有精确恢复流程不变。

执行前读取与实际写入之间仍可能有外部同路径写入；本切片不声称防止该窗口中的覆盖或提供 OS 级写者隔离。证明只限定将要交付的精确内容。
