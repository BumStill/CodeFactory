# Workspace 顶栏收敛业务设计

## 问题

Workspace 顶栏同时承载会话操作、主题切换、Git、检查点、画像、进化、评测、资源与控制平面。低频治理入口与当前任务操作处于同一层级，用户需要辨认一排无文字图标，且每新增能力都会继续挤压会话标题和模型选择。

独立规范与计划入口还把本应随代码库存在、由会话内部执行的工程资产包装成 Agent 私有产品面，造成“规范属于哪个 Agent”的错误心智。

## 决策

- Workspace 顶栏只保留当前会话必须即时操作的入口：新会话、模型、推理强度、Git 状态、检查点和设置。
- 主题切换归入设置「外观」。画像、进化审查、能力评测、资源中心和 AI Coding OS 归入设置「功能」。
- 规范与计划不进入设置，也不保留独立页面；规范文件随仓库存在，计划/任务拆解由会话执行内部生成，仅在已有执行记录时展示详情。
- Welcome 是开始工作的辅助面，不承担完整分析。它只显示紧凑的今日摘要与 28 天趋势；完整日历留在设置「用量与预算」。

## 成功标准

- 用户无需识别一排无文字图标即可理解 Workspace 顶栏。
- 所有被移动的低频能力仍可从设置「功能」到达，不形成死路。
- 规范/计划不再拥有 Agent 级独立入口，仓库文件与会话执行成为唯一真相面。
- 800×600 下会话标题、模型、Git、检查点和设置不重叠；Welcome 首屏可看到任务建议。
