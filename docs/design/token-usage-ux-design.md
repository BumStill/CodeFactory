# Token 用量与预算 UX 设计

## 1. 信息架构

Token 用量分为三个层级，不建立重复看板：

1. **新会话**：今日摘要 + 28 天迷你消耗地图，帮助开始前决策。
2. **设置 → 用量与预算**：完整指标、年度消耗地图、拆分、预算和高消耗会话。
3. **Workspace 底栏**：当前会话用量 + 上下文窗口，点击进入带当前会话过滤的详情。

现有 Profile「成本透视」迁出且不保留第二套统计或预算入口；用户通过新会话摘要、Workspace 底栏或设置首个一级 tab 进入唯一看板。

## 2. Primary User Path

1. 用户打开 CodeFactory 并创建或进入一个尚未发送消息的持久会话。
2. 当前上下文卡下方显示“今日用量”，包含 Token、请求次数、成本语义和预算/7 日均值。
3. 用户通过 28 天迷你地图看到近期某几天显著偏高，点击“查看详情”。
4. 设置自动打开「用量与预算」，默认范围为今天；用户切换到一年地图。
5. 用户键盘聚焦或鼠标悬浮某天，读取精确 Token、请求、成本语义和当天最高消耗会话。
6. 用户选择该日，页面下方同步展示执行入口和 Top 会话。
7. 用户打开 Top 会话，并进入对应 session 或端到端作业日志判断异常来源。

## 3. 新会话今日摘要

位置：`WelcomeScreen` 当前上下文卡之后、示例 Prompt 之前。最大宽度与现有内容一致。

```text
今日用量                                      查看详情 →
24.1M Tokens  ·  195 次请求  ·  订阅流量
输入 23.9M  ·  输出 204K
████████░░  已使用日预算 80%

最近 28 天   ░▒▓▓░·▒█▓░▒··░▓█▒░░▓▒█░
```

展示规则：

- 未配置预算：隐藏进度条，改为“较最近 7 个完整日均值 +18%”；样本不足时显示“已有 N 天数据”。
- 多种成本语义：显示“实际 $X · 估算 $Y · 含订阅/本地”，不合并成一个值。
- anonymous：显示“本次临时用量 N · 不计入今日”，不展示历史地图或预算累计。
- 无已采集记录：显示“今天尚无已计量请求”；采集不可用则显示“用量统计暂不可用”，二者文案和图形不同。
- 新记录在 2 秒内刷新，数值更新使用轻量过渡，不让整卡闪烁或抢焦点。
- 卡片整体不是唯一可点击目标；“查看详情”和每个日期格均使用真实 button/link。

新增一级 tab「用量与预算」并放在设置页首位，避免把高频可观测入口埋在账户或高级配置之后。页面从上到下为：

```text

[总 Tokens] [请求数] [实际/估算/订阅] [缓存命中]

[近90天 | 半年 | 一年]
      一 二 三 四 五 六 日
七月  ░ ▒ ▓ █ · · ░ ...
六月  ▒ ░ █ █ ▓ ▒ · ...
少    □ ░ ▒ ▓ █    多       □ 无数据   ⚠ 超预算

执行入口拆分
```

## 5. GitHub 风格 Token 消耗地图

### 5.1 数据与颜色

- 每个格子代表一个当地自然日；默认展示最近一年并标记今天。
- `Tokens` 模式使用选中区间非零值的对数分档，避免单个超大任务压平其他日期。图例必须说明为相对强度，不暗示各年份可直接按色阶比较。
- `预算占比` 使用固定档：`0`、`0–25%`、`25–50%`、`50–80%`、`80–100%`、`>100%`，可跨区间比较。
- `请求次数` 使用当前范围分位档。
- 已采集为零用最浅实心格；没有数据、迁移未覆盖或统计不可用使用带斜线/空心格，不能与零相同。
- 超预算除颜色外增加 `!`/警示角标或明显边框；今天使用独立外框；不只依赖红绿色。

### 5.2 交互

- Hover 或 focus 展示：日期、总 Token、input/output、reasoning/cache（可用时）、请求次数、实际/估算/订阅成本语义、Top 会话。
- 点击/Enter/Space 选中日期并更新下方详情；Escape 清除日期选择并把焦点还给原格子。
- 键盘方向键在相邻日期移动；Home/End 移到周首/周末；tooltip 不截断重要数字。
- 每个格子的可访问名称至少包含“2026-07-22，24.1M Tokens，195 次请求，超过预算”；无数据读作“统计不可用”，零读作“0 Tokens”。
- 长范围切换后优先保持当前日期；日期不在范围内时聚焦范围首个可用日。

### 5.3 窄窗口

- 390×812 下地图放在可横向滚动的专属区域，时间范围、指标切换和图例固定在区域外，不造成整页水平溢出。
- 页面提供“按月列表”替代视图；格子尺寸不得缩小到不可操作。
- tooltip 在窄屏改为点击后的内联详情，不悬浮遮挡地图。

## 6. 指标卡、拆分与高消耗会话

- “费用”卡不得统一叫“花费”。根据数据分为实际费用、估算费用、订阅/本地三行；全部不可用时显示“不可用”，不显示 `$0`。
- 缓存命中不可用时隐藏该卡并扩展其他卡，不用 0% 冒充没有命中。
- 执行入口固定为交互会话、自主任务、子 Agent、Evals；总和与总 Token 不一致时显示数据质量告警。
- Top 会话默认按 Token 降序，显示其占选中日期/范围的比例；过长标题截断但提供完整 accessible name。
- “查看会话”和“查看作业日志”是独立动作。没有作业日志时不显示假的入口。
- 高消耗只表示资源集中，不使用“低效”“浪费”等质量判断；需要用户通过日志裁决。

## 7. 预算与提醒

- 支持全局日 Token 预算和月 Token 预算；空值代表未配置。
- 默认阈值为 50%、80%、100%，用户可关闭提醒但不能关闭计量。
- 首版只做应用内提示和系统通知（若已有通知能力）；不自动停止任务、切模型、降推理或修改权限。
- 同一周期同一阈值只提醒一次；跨多个阈值合并成当前最高阈值提醒。
- 超预算状态在新会话、设置 KPI 和地图格三处一致，但只有设置页提供编辑入口。

## 8. Workspace 底栏

保持现有紧凑状态栏：

```text
会话 2.4M   今日 24.1M   订阅流量       上下文 80K/128K 63%
```

- “会话/今日”可点击，分别进入带 session/today 过滤的设置页。
- 上下文窗口不是累计 Token，继续单独展示，禁止合并为一个进度。
- 旧“本月估算美元”仅在真的存在估算费用时显示为“本月估算”；订阅不能换算成该值。

## 9. 状态、文案与隐私

| 状态 | 文案 | 行为 |
| --- | --- | --- |
| loading | 正在读取本机用量 | 保留稳定骨架，不显示 0 |
| zero | 今天尚无已计量请求 | 地图显示已采集零值 |
| unavailable | 用量统计暂不可用 | 提供重试，保留上次更新时间 |
| partial | 部分请求缺少 Provider Usage | 显示警示和覆盖计数，不补虚假值 |
| backfilled | 历史数据由会话 Usage 回填 | tooltip/页注标注，费用明细可能缺失 |
| anonymous | 本次临时用量，不计入今日 | 不进入历史、预算或 Top 会话 |

页面只展示计量、会话标题、模型、入口和有限路径信息，不展示 prompt、reasoning、工具参数、API key 或原始 Provider payload。

## 10. 实地验收

真实 App 必须至少走过：

- 新会话零数据、已有数据、订阅、实际费用和统计失败状态。
- 工具多轮运行时数值连续增加，最终轮不会覆盖此前轮次。
- 一年地图 hover/focus/click、日期筛选、Top 会话和日志深链。
- 预算 50/80/100%、跨阈值、关闭提醒和次日重置。
- 1366×768 与 390×812 的地图、筛选、内联详情和无整页水平溢出。
- 重启后数据恢复；anonymous 重启后消失且持久总量不变。

本机锁屏时继续运行 headless 双视口门禁，不请求用户解锁；Tauri 壳和发布产物由远端 macOS runner/Windows 安装包 smoke 证明。完成发布产物主路径前保持 `not live`。
