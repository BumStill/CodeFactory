# Objective 受管工作区：UX 设计

## 状态模型

UI 使用三个独立投影，不再以单个分支图标红点表达全部风险：

- 本地工作区：`准备中 / 已隔离 / 需系统核对 / 已保留 / 已清理`
- 远端交付：`未开始 / PR / CI / 合并 / 发布`
- 当前所有者：`CodeFactory 执行中 / 系统恢复中 / 已结束`

## 默认呈现

- Implement/Deliver admission 后，在首个工具卡前显示“正在准备独立工作区”。
- 分配完成显示短分支名与“根目录未改动”；路径默认折叠，避免噪音和隐私泄露。
- workspace 事故属于系统恢复，不显示“继续/重试/重新发送”按钮。
- 合并完成但尚未清理时显示“代码已合并，正在安全清理”，不能倒退成执行中。

## 边界文案

- identity 冲突：`工作区身份与任务记录不一致；系统已停止写入并进行只读核对。`
- dirty 保留：`代码已合并，但工作区仍有未提交内容，已保留以避免丢失。`
- 非 Git：`此目录不是 Git 仓库，将在所选目录中执行；不会显示分支或 PR 隔离状态。`

## 本期 UI 范围

本期提供后端持久状态、会话查询与实时事件；会话头显示“受管 worktree”或“工作区异常”，副标题展示 Objective branch/path，Git 与 delivery 面板统一切到受管路径。独立 workspace inspector 与 closeout 详情面板后续实现。验收仍要求真实 App 中证明 tool cwd 是受管 worktree 且根目录状态不变。
