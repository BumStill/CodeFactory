# 模型运行时控制面 UX 设计

## 设置页：端点与账号

ChatGPT 端点卡片按状态显示：

### 已连接

```text
ChatGPT
已连接 · leo@example.com · Plus
用于新会话：gpt-5.5 · 首选

[设为新会话默认] [重新验证] [退出登录]
```

“重新验证”主动开始新授权，不要求用户先退出。设置页说明这里只修改新会话默认值，
不会改变已存在会话。

### 需要重新验证

```text
ChatGPT 授权已过期
重新验证后可以回到原会话继续，不会删除历史记录。

[重新验证]
```

### 等待验证

```text
在浏览器中完成 ChatGPT 验证
验证链接 4:52 后到期。若浏览器没有自动打开，可手动打开或复制链接。

[打开验证页面] [复制链接] [取消]
```

不得显示未经证实的“已在浏览器中打开”。自动打开失败只增加一句低干扰说明，手动入口
保持可用。如果系统 opener 整体不可用，“打开验证页面”应明确报错，但“复制链接”仍必须
成功且使用同一 URL。链接到期后主按钮变为“生成新的验证链接”。

## 会话页：模型控制

会话顶栏模型入口显示：

```text
ChatGPT / gpt-5.5 · 首选  ▾
```

展开后按顺序编辑：

1. 策略：固定 / 首选 / 自动；
2. 固定或首选时选择端点；
3. 固定或首选时选择模型；
4. 一句策略说明和生效边界。

文案：

- 固定：只使用这个模型；失败时系统在原 route 恢复，不跨端点。
- 首选：优先使用这个模型；发送前且可安全重放时允许兼容模型接管。
- 自动：按消息能力和端点状态选择；每轮显示实际使用模型。

如果当前回合运行中，选择器保持可操作但显示：

> 已保存，下一轮生效。当前回合仍使用 ChatGPT / gpt-5.5。

切换会话后，每个会话恢复自己的端点、模型和策略。修改会话不得出现“已设为默认”或改变
设置页新会话默认值。

## 会话页：授权恢复

当实际候选返回 `AUTH_EXPIRED`：

```text
ChatGPT 授权已过期
重新验证后，系统会从安全检查点继续；不会盲目重放已完成工具或未知副作用。

[重新验证] [更换本会话模型]
```

点击“重新验证”在原位置展开与设置页相同的等待验证内容：

```text
[打开验证页面] [复制链接] [取消]
```

验证成功：

```text
ChatGPT 已重新连接。
正在核对已完成工具和副作用，并从安全检查点继续。
```

授权恢复只解除账号等待。系统依据持久化 output/side-effect latch、tool receipt 与 resume cursor
选择安全续接或只读对账；不创建新用户消息，也不重复已完成工具。

## 凭据权限提示

`CREDENTIAL_ACCESS_REQUIRED`：

```text
需要读取 DeepSeek 凭据
macOS 正在请求一次系统授权。允许后，本次会话会自动继续使用该端点。

[查看授权说明]
```

“查看授权说明”不触发第二次 Keychain lookup。未被当前回合选中的端点不显示此提示，也不得提前弹系统授权；channel timeout 后 objective 继续由系统持有，通道恢复时自动续接。

设置页凭据说明：

> macOS 本机可用性模式：凭据保存在系统钥匙串，并保留一份仅当前用户可读的本机副本，
> 以避免模型调用反复请求系统授权。删除凭据会同时删除两处副本。

## 能力不匹配

带图片但候选不支持图片时：

```text
当前模型不支持图片输入
图片仍保留在会话中。请选择支持图片的模型后再发送。

[更换本会话模型]
```

不显示“已自动移除图片后重试”。用户消息中的图片继续以内联预览显示，预览失败才降级为
带文件名的附件块。

## 视口与可访问性

- 1366×768：模型弹层不遮挡输入区，授权动作无需滚动即可看到。
- 800×600：端点、模型和策略可纵向排列，无横向滚动。
- 390×844：按钮自动换行，授权 URL 不直接裸露撑宽页面。
- 状态变化使用 `role="status"` 与 `aria-live="polite"`。
- 主动作字体不小于 12px；正文和错误说明不使用与正常正文差距过大的 10/11px。
- 不仅依赖颜色区分已连接、过期和失败。
