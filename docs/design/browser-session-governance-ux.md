# 浏览器会话治理：UX 与操作设计

## 默认体验

模型调用浏览器时，工具输出显示“已创建受管浏览器会话”、所属任务和当前状态。用户无需输入或保存 session 名称。

## 可见性与控制

设置页新增“浏览器会话”区域：显示当前受管会话的任务、最后活动时间和状态；提供“结束会话”操作。结束前说明仅影响 CodeFactory 创建的自动化浏览器，不影响用户 Chrome。

## 失败提示

当模型尝试在 `bash` 中直接运行 Playwright 时，返回明确错误：该命令未被执行；请使用 `browser_session`。当会话被自动回收时，在任务事件中显示回收原因和最后活动时间。

## 无障碍与安全

状态和结束按钮有可读名称；不会显示认证 cookie、令牌或页面内容。手动结束会话属于可逆的任务控制操作，不关闭普通浏览器窗口。
